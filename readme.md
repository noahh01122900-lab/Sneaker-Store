# 🏃 Velocity Sneaker Store

A modern sneaker e-commerce website built with **HTML, CSS, and JavaScript**.

The project focuses on creating a clean and interactive shopping experience with product cards, favorites, and a functional shopping cart.

## 📸 Preview

A sneaker store homepage inspired by modern sportswear e-commerce websites.

## ✨ Features

- 🏠 Modern homepage
- 🧭 Navigation bar
- 🔍 Search interface
- 👟 Product cards
- ⭐ Product ratings
- ❤️ Favorite button
- 🛒 Shopping cart
- ➕ Add products to cart
- ➖ Increase/decrease product quantity
- ❌ Remove products from cart
- 💰 Automatic total price calculation
- ✨ Product hover animations
- 📱 Responsive design *(coming soon)*

## 🛠️ Technologies

- **HTML5** — Website structure
- **CSS3** — Styling, layout, and animations
- **JavaScript** — Cart functionality and interactions
